# Roadmap

Ordered by value for the effort, not by date.

**Done (unreleased 0.2)**
- Cloud look-dev: density-weighted multiple-scatter fill (bright tops, blue shadowed bases), a warm low-sun and
  backlit solution with a forward-scatter halo, a warmer sunset deck, and a per-layer optical-depth budget for the
  scene's volume step rate.

**Next (0.2)**
- Clouds at distance: an impostor ring or 2D deck blend so the 15 km domain edge never shows near the horizon.
- Auto exposure from the physical illuminance (`physics.exposure_ev` exists, unused).
- Panels drawn and used in a real session; fix whatever that finds.

**Soon**
- Cloud shadow-caster plane ("gobo") for EEVEE, where volumetric shadows are expensive.
- Bake time to keyframes for render farms that do not load add-ons.
- Planets (Venus, Mars, Jupiter, Saturn) from low-precision elements; the five bright ones as discs.
- Aurora layer driven by a latitude/activity setting.
- Constellation lines and name labels as an optional debug overlay.
- Hybrid mode: blend a user HDRI with the procedural sky.
- Mesh-to-cloud: turn any mesh into a cloud shape; mesh-aware cloud avoidance.

**Later**
- Curved-planet sky for high altitude and space views.
- Wind field coupling with RainFX (shared wind vector) and fog/rain interaction.
- A machine-checked star catalogue (Hipparcos subset) replacing the hand-entered one.
- Preset thumbnails generated by `tools/render_preview.py` shown in the preset menu.

**Explicitly out of scope**: weather simulation, live weather feeds, photographic HDRI libraries.
